# **Portfolio — Muyideen Abdulhakeem**

A personal developer portfolio built with **vanilla HTML, CSS, and JavaScript**. It showcases my work, skills, interests, and journey as a Computer Science student and developer.

**🌐 Live Site:** https://bigmuak-portfolio-site.vercel.app/

---

## **Overview**

This is a **single-page portfolio website** designed to present my projects, technical skills, experience, and interests in a clean and interactive way.

The site is built from scratch without a frontend framework or build tool, keeping the project lightweight and easy to understand.

---

## **Features**

* **Responsive layout** for desktop and mobile
* **Mobile navigation menu**
* **Light/dark theme toggle**
* **Scroll-based navigation highlighting**
* **Reveal-on-scroll animations**
* **Interactive project cards**
* **Card tilt effects**
* **Magnetic buttons**
* **Interactive color roller**
* Structured sections for **About, Work, Playground, Toolkit, Journey, and Contact**

---

## **Tech Stack**

* **HTML5** — Page structure and content
* **CSS3** — Styling, responsive layouts, animations, and theme system
* **JavaScript** — Interactions, animations, navigation, and UI behavior

## **Running Locally**

No build tools or dependencies are required. This is a plain **HTML/CSS/JavaScript** project.

### **Option 1 — Open Directly**

Simply open `index.html` in your browser.

### **Option 2 — Run a Local Server**

For a more reliable local development experience:

```bash
cd portfolio-site
python3 -m http.server 8000
```

Then open:

**http://localhost:8000**
